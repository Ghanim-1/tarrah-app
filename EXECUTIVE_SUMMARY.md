

### Step 3: Access

- **Login:** admin / admin123

## 📈 PROFIT CALCULATION

Automatic profit calculation:

**For Products:**
```
Profit = Selling Price - Purchase Price
Example: 280 OMR - 150 OMR = 130 OMR profit
```

**For Services:**
```
Profit = Price Charged - Cost
Example: 25 OMR - 5 OMR = 20 OMR profit
```

**Monthly Total:**
```
Total Profit = All Product Profits + All Service Profits
All calculated and displayed automatically
```
