## 🎯 HOW TO USE

### Adding Your First Product
```
1. Click "المخزون" (Inventory)
2. Click "+ إضافة منتج جديد" (Add Product)
3. Enter: Code, Name, Color, Price
4. Upload image
5. Save
✓ Done!
```

### Recording Your First Sale
```
1. Find product in Inventory
2. Click "بيع" (Sell)
3. Enter: Selling Price, Date, Customer
4. Save
✓ Profit calculated automatically!
```

### Creating Your First Report
```
1. Click "التقارير" (Reports)
2. Select period: Daily/Weekly/Monthly/Yearly
3. Click "إنشاء التقرير" (Generate)
4. Click "تصدير PDF" or "تصدير CSV"
✓ Done!
```
